# 💻 IFC - Araquari

Organização educacional destinada às atividades relacionadas ao Desenvolvimento
Web dos cursos do Instituto Federal Catarinense — Campus Araquari.

Este espaço reúne projetos, exercícios, avaliações, desafios e materiais
desenvolvidos durante as aulas.

## 🎓 Cursos participantes

Esta organização reúne projetos de componentes curriculares relacionados ao
Desenvolvimento Web nos cursos técnicos e superiores do IFC Campus Araquari.

### 🖥️ Ensino Técnico Integrado

#### [Técnico em Informática para Internet](https://informatica.memoria.araquari.ifc.edu.br/)

Curso técnico integrado ao Ensino Médio, com formação voltada ao desenvolvimento
de aplicações, interfaces e soluções para a internet.

Prefixo utilizado nos repositórios:

```text
tec-
```

### 🌐 Ensino Superior

#### [Tecnologia em Redes de Computadores](https://redes.memoria.araquari.ifc.edu.br/)

Curso superior de tecnologia voltado à infraestrutura, administração,
segurança e programação aplicada às redes de computadores.

Prefixo utilizado nos repositórios:

```text
rc-
```

#### [Bacharelado em Sistemas de Informação](https://bsi.memoria.araquari.ifc.edu.br/)

Curso superior voltado ao planejamento, desenvolvimento, implantação e
gerenciamento de sistemas, serviços e recursos de Tecnologia da Informação.

Prefixo utilizado nos repositórios:

```text
bsi-
```

## 🎯 Objetivo

Este espaço tem como objetivo organizar e preservar os projetos, exercícios,
avaliações, desafios e materiais produzidos nas disciplinas relacionadas ao
Desenvolvimento Web.

Por meio dos repositórios, os estudantes poderão praticar:

- HTML semântico;
- CSS, Flexbox e CSS Grid;
- JavaScript;
- Vue.js;
- Git e GitHub;
- organização de projetos;
- desenvolvimento de interfaces;
- trabalho colaborativo;
- publicação de aplicações web.

---

## 🗂️ Nomenclatura dos repositórios

Para facilitar a identificação, a pesquisa e a organização dos projetos,
recomendamos que os repositórios sigam o seguinte padrão:

```text
[abreviacao-do-curso]-[disciplina]-[projeto]
```

Os nomes devem ser escritos:

- com letras minúsculas;
- sem acentos;
- sem espaços;
- com as palavras separadas por hífen;
- de maneira curta, mas suficientemente descritiva.

### Abreviações dos cursos

| Abreviação | Curso |
| --- | --- |
| `tec` | Técnico em Informática para Internet |
| `rc` | Tecnologia em Redes de Computadores |
| `bsi` | Bacharelado em Sistemas de Informação |

Novas abreviações poderão ser acrescentadas conforme outros cursos e professores
adotarem a organização.

### Exemplo

Para um projeto sobre fundamentos da disciplina de Desenvolvimento Web 1,
do curso de Tecnologia em Redes de Computadores:

```text
rc-web1-fundamentos
```

Nesse exemplo:

| Parte | Significado |
| --- | --- |
| `rc` | Tecnologia em Redes de Computadores |
| `web1` | Desenvolvimento Web 1 |
| `fundamentos` | Nome ou finalidade do projeto |

### Outros exemplos

```text
rc-web1-fundamentos
rc-web1-portal-noticias
tec-web2-starter
tec-web2-feira-facil-app
tec-web2-cidades-sustentaveis
bsi-web1-projeto-final
bsi-poo-sistema-academico
```

> Antes de criar um repositório, verifique se já existe outro projeto com nome
> ou finalidade semelhante.

> Os repositórios anteriores à adoção desta convenção poderão ser renomeados
> gradualmente.

## 📚 Organização dos projetos

Cada repositório deve representar uma disciplina, atividade, avaliação ou
projeto específico.

A identificação do curso, da disciplina e da finalidade do projeto deverá ser
feita por meio do nome do repositório e das informações apresentadas no seu
`README.md`.

Exemplos:

| Repositório | Finalidade |
| --- | --- |
| `rc-web1-fundamentos` | Projeto progressivo de HTML, CSS e JavaScript |
| `rc-web1-portal-noticias` | Desenvolvimento de um portal de notícias |
| `tec-web2-starter` | Projeto introdutório da disciplina de Desenvolvimento Web 2 |
| `tec-web2-feira-facil-app` | Avaliação prática individual desenvolvida com Vue.js |
| `tec-web2-cidades-sustentaveis` | Projeto com Vue.js e consumo de dados públicos |
| `bsi-poo-sistema-academico` | Projeto relacionado à Programação Orientada a Objetos |

---

## ✅ Boas práticas

Os professores que utilizarem esta organização devem incluir, no início do
`README.md` de cada projeto, informações que permitam aos estudantes identificar
facilmente o curso, a disciplina, o responsável e as tecnologias utilizadas.

### Modelo recomendado

```md
# Nome do projeto

Breve descrição do objetivo e do contexto da atividade.

| Informação | Descrição |
| --- | --- |
| Curso | Tecnologia em Redes de Computadores |
| Disciplina | Desenvolvimento Web 1 |
| Professor | Cristofer Sousa |
| Instituição | IFC — Campus Araquari |
| Tecnologias | HTML, CSS e JavaScript |
```

Também é recomendado que o README apresente:

- objetivo do projeto;
- contexto da atividade;
- conteúdos trabalhados;
- pré-requisitos;
- instruções de instalação e execução;
- estrutura de pastas;
- funcionalidades solicitadas;
- critérios de avaliação, quando aplicável;
- orientações para entrega;
- referências e materiais de apoio.

## 🧑‍🎓 Orientações para os estudantes

Antes de iniciar uma atividade:

1. leia integralmente o README do repositório;
2. consulte os requisitos da atividade;
3. siga as orientações para criar um fork, repositório ou branch;
4. instale as dependências, quando necessário;
5. faça commits pequenos e descritivos;
6. teste o funcionamento do projeto;
7. verifique se não existem erros no console;
8. publique a aplicação quando solicitado;
9. envie o endereço correto do repositório.

A pasta `node_modules` e outros arquivos gerados localmente não deverão ser
enviados ao repositório.

## 🤖 Uso de Inteligência Artificial

As ferramentas de Inteligência Artificial devem ser utilizadas de maneira
ética, crítica e compatível com as orientações de cada atividade.

O professor deverá informar no README da atividade se o uso de IA é:

- permitido;
- permitido apenas para consulta;
- permitido com declaração das ferramentas utilizadas;
- parcialmente limitado;
- proibido durante a avaliação.

Quando autorizada, a utilização de IA não elimina a responsabilidade do
estudante sobre o conteúdo entregue.

O estudante deverá:

- compreender o código apresentado;
- ser capaz de explicar sua implementação;
- informar as ferramentas utilizadas quando solicitado;
- revisar e testar todo conteúdo gerado;
- respeitar as regras específicas da atividade.

O professor poderá solicitar que o estudante explique ou modifique partes da
solução apresentada para verificar a compreensão e a autoria do trabalho.

## 🤝 Convivência e colaboração

Este é um ambiente educacional. Esperamos de todos:

- respeito entre os participantes;
- responsabilidade com o código;
- autoria e indicação das fontes utilizadas;
- cuidado com dados pessoais;
- colaboração durante as atividades;
- comunicação adequada;
- uso ético das ferramentas de Inteligência Artificial.

Não deverão ser publicados:

- senhas;
- tokens de acesso;
- chaves de API;
- informações pessoais sensíveis;
- dados de estudantes;
- documentos institucionais restritos.
