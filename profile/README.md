# 💻 IFC Dev Web

Organização educacional destinada às atividades de Desenvolvimento Web

## 🎓 Cursos participantes

Esta organização reúne projetos e atividades desenvolvidos em componentes
curriculares relacionados ao Desenvolvimento Web no IFC Campus Araquari.

### 🖥️ Ensino Técnico Integrado

[**Técnico em Informática para Internet**](https://informatica.memoria.araquari.ifc.edu.br/)

Curso técnico integrado ao Ensino Médio, com formação voltada ao desenvolvimento
de aplicações, interfaces e soluções para a internet.

### 🌐 Ensino Superior

[**Tecnologia em Redes de Computadores**](http://redes.memoria.araquari.ifc.edu.br/)

Curso superior de tecnologia voltado à infraestrutura, administração,
segurança e programação aplicada às redes de computadores.

## 🎯 Objetivo

Este espaço reúne projetos, exercícios, desafios e materiais desenvolvidos
durante as aulas de Desenvolvimento Web.

Aqui, os estudantes poderão praticar:

- HTML semântico;
- CSS, Flexbox e CSS Grid;
- JavaScript;
- Vue.js;
- Git e GitHub;
- organização de projetos;
- trabalho colaborativo;
- publicação de aplicações web.

## 📚 Organização dos projetos

Os repositórios são organizados conforme a turma, o conteúdo e o ano letivo.

Exemplos:

- `dev-web-2info`;
- `profile-ifc`;
- `coffee-quality-challenge`;
- `hacka-ifc`;
- `vue-layout-challenge`.

## 🧑‍🎓 Para os estudantes

Antes de iniciar uma atividade:

1. Leia o README do repositório.
2. Consulte os requisitos da atividade.
3. Crie seu projeto ou sua branch conforme a orientação.
4. Faça commits pequenos e descritivos.
5. Confira o funcionamento antes da entrega.
6. Publique o projeto quando solicitado.

## 🤝 Convivência e colaboração

Este é um ambiente educacional. Esperamos de todos:

- respeito entre os participantes;
- responsabilidade com o código;
- autoria e indicação das fontes utilizadas;
- cuidado com dados pessoais;
- colaboração durante as atividades;
- uso ético das ferramentas de inteligência artificial.
